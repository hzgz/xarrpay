## 2. 问题现象

系统已经将网站名称写入系统设置，但部分页面和编译后的前端资源仍然存在旧默认品牌：

1. 后端配置接口和支付相关接口存在默认名称回退风险。
2. 前台、支付页、商户中心、后台和收银台的静态 HTML 标题可能先显示旧标题。
3. 安装页面的编译 bundle 仍显示旧品牌和旧官网地址。
4. 后台编译 bundle 仍将页面标题固定拼接为“后台管理系统”。
5. `public/site-branding.js` 仍通过判断旧品牌清理标题，逻辑依赖固定名称。

## 3. 名称字段约定

运行时网站名称只从数据库 `options` 表读取：

```text
web_title
web_index_title
```

字段作用：

- `web_title`：系统网站名称，供后台、商户中心、支付页、收银台和通用页面使用。
- `web_index_title`：首页标题，供网站首页使用。

未配置时：

- 接口返回空字符串。
- 页面标题不写入任何程序默认品牌。
- 收银台商户名称缺失时返回中文错误“收银台商户名称未配置”。
- MFA 发行者缺失时返回中文错误“系统网站名称未配置，请先在系统设置中填写”。
