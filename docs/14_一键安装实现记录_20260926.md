# 一键安装逻辑实现记录 2026-09-26

本记录从 0 记录本轮“一键安装逻辑”改动，方便下次更新时直接核对。

## 实现边界

- 只处理 `C:\Users\Administrator\Desktop\重构PHP` 目录。
- 安装器只允许全新空库安装。
- 已安装、非空库、已有管理员时直接中文失败。
- 不做旧库迁移、不清库覆盖、不生成演示商户、不写假订单或假收款账号。
- 后台入口当前 PHP 版本固定为 `admin`；安装页保留字段，但提交非 `admin` 会拒绝。

## 修改文件

### `src/Support/Config.php`

- 新增 `.env` 加载。
- 运行时先保留服务器真实环境变量，只有环境变量不存在或为空时才读取项目根目录 `.env`。
- 读取双引号配置值时还原安装器写入的转义字符，避免数据库密码包含引号或反斜杠时连接失败。
- 作用：一键安装写出的 `.env` 能被后续 PHP 请求实际读取，不再只是写文件但程序不用。

### `src/Http/Controllers/InstallController.php`

新增安装控制器，承接安装前端已经预留的接口：

- `GET /api/install/progress`
- `POST /api/install/authorize`
- `GET /api/install/conf`
- `POST /api/install/database`
- `GET /api/install/init`
- `POST /api/install/basic`
- `POST /api/install/end`

主要逻辑：

- 授权码：只做本地保存，不访问外部授权服务。
- 数据库配置：支持 MySQL；显式传 `driver=sqlite` 或 `dsn=sqlite:...` 时支持项目目录内 SQLite。
- 切换数据库类型时清理另一种连接配置，避免旧 `XARR_DB_DSN` 覆盖新 MySQL 配置。
- 空库校验：MySQL 检查 `information_schema.tables`，SQLite 检查 `sqlite_master`。
- 初始化：按数据库类型导入 `database/schema.mysql.sql` 或 `database/schema.sqlite.sql`。
- 默认系统数据：只写必要系统选项和支付类型 `alipay`、`wechat`；不创建商户、订单、支付账号。
- 管理员创建：写入 `staff`，密码沿用现有系统的 `md5()` 存储方式。
- 安装完成判定：`staff` 表存在且至少 1 个管理员才视为已安装。
- 重复安装保护：已安装后安装接口返回中文错误，不覆盖已有数据。

### `src/Application.php`

- 注册 `/api/install/*` 后端路由。
- 动态请求统一执行安装态守卫：没有安装锁时，除安装页和安装接口外全部 302 到 `/install`；已有安装锁时，重新访问安装页 302 回 `/`。
- 作用：安装静态页可以直接调用真实 PHP 安装接口。

### `src/Support/InstallState.php`

- 新增显式安装锁状态管理。
- 默认锁文件：`var/install.lock`。
- 安装锁为 JSON，包含版本、安装时间、后台路径和管理员账号。
- 锁文件创建后权限设置为只读，并且禁止覆盖已有锁。
- 作用：安装完成后不再通过“数据库里是否有管理员”推断安装状态，安装态由明确锁文件决定。

### `public/router.php`

- 在 PHP 内置服务器入口执行同一安装态守卫。
- 未安装时只放行 `/install`、`/install/*` 和 `/api/install/*`。
- 已安装时重新请求 `/install/*` 跳回 `/`。
- 作用：本地启动和 PHP-FPM 动态入口使用同一套安装态规则。

### `public/install/static/js/staff-eed801ad.js`

- 将后台路径默认值从随机字符串改为 `admin`。
- 将“随机后台路径”按钮改为仍保持 `admin`。
- 修改字段帮助文案，说明当前 PHP 版本后台入口固定为 `admin`。
- 作用：避免安装成功页跳到一个当前后端并不支持的随机后台路径。

### `public/install/index.html`

- 将安装页的 JS、CSS、modulepreload 资源从错误的根路径 `/static/*` 改为 `/install/static/*`。
- 原因：项目路由会把 `/static/*` 映射到商户前台静态目录，安装包资源会 404。
- 作用：安装页可以实际加载 Vue、TDesign 和安装步骤脚本。

### `public/install/static/js/db-53a0da9e.js`

- 将“会清空已有数据库”提示改为“只允许空数据库安装”。
- 重装确认文案改为要求人工准备全新空库。
- 作用：前端提示与后端真实策略一致。

### `public/install/static/js/init-6bb9b2e9.js`

- 将“删除所有表清空安装”提示改为“只允许全新空库，已有表或数据直接拒绝”。
- 作用：避免误导用户以为安装器会清库。

### `.env.example`

- 增加 `XARR_ADMIN_PATH=admin` 和 `XARR_LICENSE_CODE=`。
- 作用：记录安装器会写入/读取的配置字段。

### `tests/InstallFlowTest.php`

新增真实 HTTP 安装流程测试：

- 启动 PHP 内置服务器。
- 使用隔离 SQLite、临时 `.env`、临时安装状态文件。
- 依次调用授权、数据库配置、SSE 初始化、管理员创建、安装完成。
- 验证重复安装会被拒绝。
- 验证只创建管理员、系统选项、支付类型，不创建假商户。

### `tests/InstallGuardTest.php`

补强安装态边界测试：

- 无安装锁时，`/`、`/admin`、`/api/health` 和未知路径 `/anything` 全部返回 `302 /install`。
- 无安装锁时安装页及安装页静态资源仍可访问。
- 写入有效安装锁后首页返回 `200`，再次访问 `/install` 返回 `302 /`。
- 删除安装锁后四类入口全部重新返回 `302 /install`。

作用：把“没有安装态必须先安装，安装成功后锁定安装态”的验收条件固定成可重复执行的测试，不依赖人工观察单一路径。

## 安装状态文件

默认路径：

```text
var/install-state.json
```

测试可通过环境变量改写：

```text
XARR_INSTALL_STATE_FILE=<临时状态文件>
XARR_INSTALL_ENV_FILE=<临时env文件>
```

生产环境不需要手动创建状态文件；安装器会自动创建。

## 下次更新核对点

- 安装页请求仍必须指向 `/api/install/*`。
- 站点 Nginx 必须保留安装锁检查：静态文件不会经过 PHP，必须在 Nginx `location = /` 和 `location /` 中检查 `var/install.lock`，否则未安装时已有 HTML/JS 文件可以绕过跳转。
- `database/schema.mysql.sql` 和 `database/schema.sqlite.sql` 新增表后，安装器不需要额外迁移；导入 schema 即可。
- 如果以后真正实现自定义后台路径，必须同时改：
  - `public/router.php` 后台静态入口；
  - `AdminController::config()` 的 `admin_path`；
  - `/api/admin` 后台接口前缀策略；
  - 安装页 `admin_path` 校验。
- 如果新增必须初始化的系统基础数据，只能写真实系统配置或字典数据，不能写演示商户、演示订单、演示支付账号。
