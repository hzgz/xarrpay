# 部署教程

## 本地验收

```powershell
php scripts/init-local.php
.\start-local.ps1 -Port 8088
```

打开 `http://127.0.0.1:8088/`，首页提供商户中心和管理后台两个入口。商户登录使用 `/login`，管理员登录使用 `/admin/login`，本地演示账号为 `admin / 123456`。支付页使用 `LOCAL-DEMO-0001`，收银台使用 `local-demo-key`。

## 生产部署

将源码部署到独立目录，DocumentRoot 指向 `public`。PHP 使用 8.1 或更高版本，并启用 `PDO`、`pdo_mysql`、`GD`、`mbstring`。生产环境只设置变量，不把真实值写入源码：

```text
XARR_RUNTIME_DIR=/www/wwwroot/xarr-php-ys
XARR_PLUGIN_DIR=/www/wwwroot/xarr-php-ys/plugins
XARR_DB_HOST=127.0.0.1
XARR_DB_PORT=3306
XARR_DB_NAME=xarrpay
XARR_DB_USER=xarrpay
XARR_DB_PASSWORD=<生产数据库密码>
XARR_DB_CHARSET=utf8mb4
```

服务器的运行态、日志、数据库和插件目录继续留在服务器；`reverse-work` 仅为分析工作目录，禁止部署。

### Nginx 静态资源映射

本包的三个前端构建使用了不同的资源前缀，站点必须保留以下映射；否则 HTML 能打开，但浏览器会把 JS/CSS 请求成 404：

```nginx
location = / {
    if (!-f /www/wwwroot/xarr-php-ys/var/install.lock) {
        return 302 /install;
    }
    try_files /index/index.html =404;
}
location = /install {
    if (-f /www/wwwroot/xarr-php-ys/var/install.lock) {
        return 302 /;
    }
    return 302 /install/;
}
location ^~ /install/ {
    if (-f /www/wwwroot/xarr-php-ys/var/install.lock) {
        return 302 /;
    }
    try_files $uri $uri/ =404;
}
location / {
    if (!-f /www/wwwroot/xarr-php-ys/var/install.lock) {
        return 302 /install;
    }
    try_files $uri $uri/ @xarr_php_ys;
}
location = /login {
    try_files /user/index.html =404;
}
location = /admin/login {
    try_files /admin/index.html =404;
}
location = /favicon.ico {
    alias /www/wwwroot/xarr-php-ys/public/admin/static/ico/favicon-6d3c559c.ico;
}
location ^~ /static/ {
    alias /www/wwwroot/xarr-php-ys/public/user/static/;
}
location ^~ /assets/ {
    alias /www/wwwroot/xarr-php-ys/public/cashier/assets/;
}
```

`/admin/static/`、`/user/static/`、`/pay/assets/` 由站点根目录直接提供；上面的 `/static/` 和 `/assets/` 是商户中心、收银台构建产物的根路径资源兼容映射，不涉及旧模板或旧运行态。

## 验收顺序

1. `GET /api/health`
2. `GET /api/config`
3. `/admin` 登录和 `/api/staff/profile`
4. `/pay/{order_id}`、`/pay/separate/{order_id}`、`/pay/status/{order_id}`
5. `/cashier/{key}`、收银台金额创建订单
6. Epay 签名下单、订单查询和异步通知

## 生产注意事项

- PHP 源码部署到独立目录，例如 `/www/wwwroot/xarr-php/`，不要覆盖现有 Go 版。
- Nginx 新建独立站点或独立 location，确认 `index.php` 通过 PHP-FPM 执行。
- PHP-FPM 用户必须能读取 `XARR_PLUGIN_DIR`，并能连接 MySQL。
- 证书、Nginx、PHP-FPM 和数据库操作必须在服务器实际管理入口完成；密码不写入本地包。
- 本包不包含生产数据库、真实商户密钥、私有 Lua 插件正文和第三方支付真实扣款动作。
