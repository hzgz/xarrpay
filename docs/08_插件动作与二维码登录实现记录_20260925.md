## 修改文件和作用

### `src/Payment/AccountPlugin.php`

- 新增账号插件动作/二维码登录接口定义。
- 作用：固定账号级插件能力边界，避免将任意前端字符串当作 Lua 函数执行。

### `src/Support/PluginAccountStore.php`

- 新增插件账号配置 JSON 保存。
- 新增账号在线/离线状态字段更新。
- 作用：二维码登录成功后只写入插件真实返回的账号配置，并记录在线状态。

### `src/Support/PluginAccountService.php`

- 新增账号插件动作入口。
- `plugin-action` 对当前四个插件返回明确中文 `501`，因为服务器 Lua 未声明可执行动作。
- 实现三类二维码登录：
  - 靓仔全能码：创建 `CreateID`、获取 `QRCode`，轮询 `IsLoginStatus`，成功后获取小程序 code 并建立会话。
  - 微信云端电脑管家：调用 `/guanjia/api/qrcode`，轮询 `/guanjia/api/status`，成功后使用 code 获取 SID。
  - 微信云端应用宝：调用 `/yyb/qr`，轮询 `/yyb/qr/{session_id}/poll`，确认账号后获取 SID。
- 所有外部请求都有超时、JSON 解析、HTTP 状态和中文错误处理。
- 二维码状态使用一次性票据，票据有效期 300 秒；未完成返回 `201`，成功才写账号配置和在线状态。

### `src/Http/Controllers/MerchantController.php`

- 新增商户鉴权、账号归属校验、插件动作、二维码创建、二维码轮询控制器。
- 账号查询必须同时匹配商户 `uid`；不存在账号返回 `404`。
- 二维码票据必须同时匹配当前商户和账号归属，不能跨商户轮询。

### `src/Application.php`

- 注册三个商户路由：
