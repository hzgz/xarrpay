# PHP 重构版目录与文件说明

更新时间：2026-09-23

## 交付目录

| 路径 | 作用 | 运行是否必须 |
|---|---|---|
| `public/` | Web 根目录、PHP 入口、静态后台/支付/收银台页面和资源 | 是 |
| `public/index/` | 新版本原程序 `templates/index/default` 首页模板及构建资源，保留官方页面与 JS/CSS bundle | 是（首页运行需要） |
| `public/index.php` | PHP API 入口 | 是 |
| `public/router.php` | PHP 内置服务器路由；Nginx/PHP-FPM 部署不依赖它 | 本地启动需要 |
| `src/` | PHP 业务代码、路由、控制器、数据库、验证码和签名实现 | 是 |
| `database/schema.sqlite.sql` | 本地 SQLite 表结构 | 本地初始化需要 |
| `scripts/init-local.php` | 创建本地演示数据库和演示数据 | 本地首次启动需要 |
| `scripts/smoke-test.php` | 本地 HTTP 全链路验收脚本，自动清理本轮测试订单 | 验收需要，运行服务不需要 |
| `scripts/browser-login-test.py` | 真实浏览器商户登录回归脚本，验证登录跳转、token、profile 和初始化接口 | 验收需要，运行服务不需要 |
| `start-local.ps1` | Windows 本地启动脚本 | 本地启动需要 |
| `deploy/` | 服务器环境变量示例和部署边界说明 | 生产部署参考 |
| `tests/EpaySignerTest.php` | Epay MD5 签名单元测试 | 验收需要，运行服务不需要 |
| `.env.example` | 不含秘密的环境变量示例 | 配置参考 |
| `README.md` | 项目入口说明、启动、检查和功能边界 | 建议保留 |
| `docs/` | 修改记录、接口清单、部署教程、运行态边界和文件说明 | 部署/维护需要 |

## 不进入纯净发布包

| 路径/内容 | 原因 |
|---|---|
| `reverse-work/` | 逆向分析证据、截图和服务器副本，不是运行文件，且可能包含敏感运行态 |
| `var/local.sqlite` | 本地测试数据库；发布包由初始化脚本按需生成 |
| `var/local-server.pid` | 当前机器的临时进程记录 |
| 服务器数据库密码、Redis 密码、真实商户密钥 | 生产秘密，只能在服务器环境配置 |
| 服务器 Lua 插件正文和日志 | 服务器运行态，按约束不复制到本地发布包 |

## 本地运行

```powershell
php scripts/init-local.php
.\start-local.ps1 -Port 8088
php scripts/smoke-test.php http://127.0.0.1:8088
python scripts/browser-login-test.py http://127.0.0.1:8088
```

首页：`http://127.0.0.1:8088/`；商户登录：`/login`；管理员登录：`/admin/login`。

本地演示账号：管理员 `admin / 123456`，商户 `coco / 123456`。

## 生产运行

生产 Web 根目录指向 `public/`，PHP 通过环境变量连接 MySQL，并从服务器读取：

```text
XARR_RUNTIME_DIR=/www/wwwroot/xarr
XARR_PLUGIN_DIR=/www/wwwroot/xarr/plugins
```

现有 Go 站点和服务器插件目录不由本包覆盖。首页静态资源使用 `/index/assets/...`，由 `public/index/` 原样提供。

生产 Nginx 还必须映射前端构建的根路径资源：

- `/` -> `public/index/index.html`（新版本原程序首页模板）
- `/login` -> `public/user/index.html`
- `/admin/login` -> `public/admin/index.html`
- `/favicon.ico` -> `public/admin/static/ico/favicon-6d3c559c.ico`
- `/static/` -> `public/user/static/`
- `/assets/` -> `public/cashier/assets/`
- `/admin/static/`、`/pay/assets/` 直接由 `public/` 根目录提供

这些映射属于站点配置，不是 PHP 源码文件；缺失时页面 HTML 仍可能返回 200，但 JS/CSS 会 404。

## GitHub 发行

源码仓库：`https://github.com/hzgz/xarrpay.git`。

每次发布流程：先跑 `smoke-test.php` 和 `browser-login-test.py`，再提交 Git，并创建新 tag。仓库只保存源码、静态资源、脚本和文档，不保存 `var/`、SQLite、日志、PID、服务器运行态、真实密钥或私有插件正文。
