# 27_系统监控面板运行态实现记录_20260927

## 背景

后台“系统监控面板”页面已存在，前端会每 `3` 秒请求：

- `GET /api/admin/system/runtime`

页面使用的是旧版 Go 后台字段名，例如：

- `sysOsName`
- `sysOsArch`
- `sysComputerName`
- `pid`
- `goRunTime`
- `goStartTime`
- `goUsed`
- `runUser`
- `cpuNum`
- `cpuUsed`
- `cpuAvg5`
- `cpuAvg15`
- `memTotal`
- `memUsed`
- `memFree`
- `memUsage`

原 PHP 接口只返回 `php_version/sapi/memory_limit` 等 PHP 配置字段，和监控面板字段不一致，会导致页面空值、`NaN` 或仪表盘无法正确显示。

## 修改内容

### 1. 补齐运行态接口字段

文件：

- `src/Http/Controllers/AdminFeatureController.php`

处理：

- `/api/admin/system/runtime` 返回旧版监控面板需要的完整字段。
- `sysOsName/sysOsArch/sysComputerName` 来自当前系统信息。
- `pid` 使用当前 PHP 进程 ID。
- `goStartTime/goRunTime` 在 Linux 下读取 `/proc/<pid>/stat` 与 `/proc/stat` 的 `btime` 计算进程启动时间和运行时长。
- `goUsed` 使用当前 PHP 进程内存。
- `runUser` 使用当前运行用户。
- `cpuNum` 优先读取 `/proc/cpuinfo`，其次读取 `nproc`，本地 Windows 测试读取 `NUMBER_OF_PROCESSORS`。
- `cpuUsed` 在 Linux 下读取 `/proc/stat`，把快照写入 `var/system-runtime-cpu.json`，下次请求按时间片差值计算真实 CPU 使用率。
- `cpuAvg5/cpuAvg15` 使用系统 load average。
- `memTotal/memUsed/memFree/memUsage` 在 Linux 下读取 `/proc/meminfo`。
- 全程不依赖 `shell_exec()`，适配线上禁用 shell 函数的 PHP 环境。

作用：

- 后台系统监控面板可以按旧版字段直接渲染。
- CPU 和内存仪表盘不再显示空值或 `NaN`。
- 线上 Linux 服务器返回真实系统资源数据。
- 本地 Windows 测试环境不会因为缺少 `sys_getloadavg()` 或 `/proc` 报 500。

### 2. 调整监控页响应式样式

文件：

- `public/admin/static/css/monitor-796a2438.css`

处理：

- `.monitor-container` 从 `min-width:400px` 改为 `min-width:0`。
- 信息网格最小列宽从 `300px` 调整为 `260px`。
- CPU/内存卡片最小列宽从 `400px` 调整为 `280px`。
- 卡片圆角统一为 `8px`。
- 标签增加最大宽度和省略号，避免长系统名撑破容器。

作用：

- 窄屏或后台内容区较小时不再强制横向溢出。
- 保留原后台卡片风格，但减少布局抖动和文本撑开问题。

### 3. 增加测试覆盖

文件：

- `tests/AdminFeatureCatalogTest.php`

新增断言：

- `/api/admin/system/runtime` 返回 HTTP/API 成功。
- 运行态字段完整。
- `pid > 0`。
- `cpuNum > 0`。
- `memTotal > 0`。

## 下次更新核对

- 系统监控面板字段名继续保持旧版 Go 面板合同，前端不用重新适配。
- CPU 百分比字段可以带 `%`，前端 `parseInt()` 可正常驱动仪表盘。
- `memTotal/memUsed/memFree/goUsed` 必须是字节数，前端会除以 `1024/1024/1024` 或 `1024/1024` 展示。
- `var/system-runtime-cpu.json` 是 CPU 使用率快照，不是业务数据，可以随部署重新生成。
