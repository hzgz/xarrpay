# 本地插件管理按钮缺失修复记录

日期：2026-09-27

## 1. 现象

后台“应用管理”页面的本地插件卡片只显示“卸载”按钮，看不到“启用”“禁用”“重载”按钮。

## 2. 根因

前端已编译脚本 `public/admin/static/js/index-0c687a8e.js` 的显示条件是：

```js
item.type === 1 || item.type === 4 || item.type === 6
```

其中：

- `1`：支付插件
- `4`：短信插件
- `6`：存储插件

前端同时根据 `status` 和 `running` 显示动作：

- `status === 2`，或 `status === 1 && running === false`：显示“启用”
- `status === 1 && running === true`：显示“禁用”和“重载”
- “卸载”不受插件类型条件限制，所以原来始终能显示

原 PHP 接口直接把插件清单中的字符串类型返回给前端，例如：

```json
{
  "type": "pay"
}
```

前端使用严格比较，字符串 `"pay"` 不等于数字 `1`，因此启用、禁用、重载全部被隐藏。

## 3. 修改内容

### 3.1 `src/Http/Controllers/AdminFeatureController.php`

修改 `appItemsList()`：

- 统一从 `appItems()` 生成应用列表
- 支持 `type` 筛选
- 支持 `query` 搜索

新增 `appItemsAction()`：

- `enable`：启用并启动插件
- `disable`：禁用并停止插件
- `reload`：清理 PHP 插件注册表缓存
- `uninstall`：卸载插件

新增 `appItemsBatchAction()`：

- 批量启用
- 批量禁用
- 批量卸载

统一适配返回字段：

- `pay` -> `type: 1`
- `sms` -> `type: 4`
- `storage` -> `type: 6`
- `index` -> `type: 2`
- `pay_template` -> `type: 3`
- `cashier` -> `type: 5`
- `enabled: true` -> `status: 1`
- `enabled: false` -> `status: 2`
- 增加 `uuid`
- 增加 `plugin_name`
- 增加 `install_status`
- 增加 `author`
- 保证 `config` 为数组

### 3.2 `src/Application.php`

注册应用管理动作接口：

```text
POST /api/admin/app-items/enable
POST /api/admin/app-items/disable
POST /api/admin/app-items/reload
POST /api/admin/app-items/uninstall
POST /api/admin/app-items/batch-enable
POST /api/admin/app-items/batch-disable
POST /api/admin/app-items/batch-uninstall
```

### 3.3 `tests/PluginHttpTest.php`

增加 HTTP 回归验证：

- 支付插件 `type` 返回数字 `1`
- 返回 `status`
- 返回 `running`
- 禁用后返回 `status: 2`、`running: false`
- 启用后返回 `status: 1`、`running: true`
- 重载接口返回成功

## 4. 修复后的显示规则

支付、短信、存储插件应显示：

- 已禁用或未运行：`启用`、`卸载`
- 正在运行：`禁用`、`重载`、`卸载`

主题类应用仍不显示启用、禁用、重载，这是前端原有设计：类型 `2/3/5` 作为主题处理。
