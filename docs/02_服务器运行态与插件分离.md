# 服务器运行态与插件分离

## 原则

本地目录只保存 PHP 源码、静态 UI、测试和不含秘密的配置示例。

服务器保存：

- 数据库连接和 Redis 配置
- `config/config.yaml`、安装锁和运行日志
- `runtime/`、上传文件和 session
- Lua 插件目录 `/www/wwwroot/xarr/plugins`

PHP 重构版通过环境变量读取这些路径，不把服务器运行态复制回本地。

## 当前服务器插件

已确认服务器存在以下支付插件：

- `epay`
- `jk_alipay`
- `jk_wechat_pc`
- `pc_wxpay_lz`
- `wechat_dianyuan`
- `yun_wechat_gj_xd`

服务器使用 LuaJIT 运行插件。本地 PHP 版第一阶段不强行把 Lua 文件转换成 PHP，先通过统一插件适配器读取 manifest、渠道配置和运行路径；具体支付动作按插件行为逐个实现或调用服务器侧桥接。

## PHP 服务器环境变量

```text
XARR_RUNTIME_DIR=/www/wwwroot/xarr
XARR_PLUGIN_DIR=/www/wwwroot/xarr/plugins
XARR_DB_HOST=127.0.0.1
XARR_DB_PORT=3306
XARR_DB_NAME=xarrpay
XARR_DB_USER=xarrpay
XARR_DB_PASSWORD=<只在服务器配置>
XARR_DB_CHARSET=utf8mb4
```

## 不允许放入本地源码的内容

- 真实数据库密码
- Redis 密码
- 商户密钥和支付渠道密钥
- 服务器运行日志
- `runtime/` 内容
- `plugins/pay/*.lua` 私有插件正文
- 生产数据库导出
