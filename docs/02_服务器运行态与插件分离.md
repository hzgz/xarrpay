# 服务器运行态与插件分离

## 原则

本地目录只保存 PHP 源码、静态 UI、测试和不含秘密的配置示例。

服务器保存：

- 数据库连接和 Redis 配置
- `config/config.yaml`、安装锁和运行日志
- `runtime/`、上传文件和 session
- 原 Go Lua 插件目录 `/www/wwwroot/xarr/plugins`（只读参考，不作为 PHP 运行目录）
- PHP 独立插件目录 `/www/wwwroot/xarr-php-ys/plugins`

PHP 重构版通过环境变量读取这些路径，不把服务器运行态复制回本地。支付插件固定从 `XARR_PLUGIN_DIR/pay/<插件名>/manifest.json` 扫描，每个插件独立维护清单、适配器入口和表单入口。

## 当前服务器插件

已确认服务器存在以下支付插件：

- `jk_wechat_app`
- `yun_qnm_lz`
- `yun_wechat_gj_xd`
- `yun_wechat_yyb_xd`

核对位置：`/www/wwwroot/xarr/plugins/pay/*`。每个插件当前包含 `manifest.json` 和 `plugin.lua`。

服务器使用 LuaJIT 运行插件。本地 PHP 版不复制私有 Lua 正文，而是根据真实 `manifest.json` 和入口契约实现 PHP adapter：

- `jk_wechat_app`：个人/赞赏/店员/商业/收款单/经营码等静态码创建；PHP 运行态负责读取客户端心跳和解析已接收的真实微信消息。
- `yun_qnm_lz`：二维码或图片收款码创建；PHP worker 负责使用真实登录态拉取账本流水并过滤收入记录。
- `yun_wechat_gj_xd`：电脑管家收款单/小账本，创建时调用对应云端接口并取得二维码；PHP worker 按后台填写的真实流水接口定时上报。
- `yun_wechat_yyb_xd`：应用宝收款单/小账本，创建协议与电脑管家插件一致，但登录入口不同；流水通过独立 PHP 运行态处理。

PHP adapter 由对应插件目录清单的 `adapter_entry` 加载。只有清单启用、运行中且入口返回名称匹配的 `PaymentPlugin` 时才允许使用。配置完整且远端接口返回成功时才返回支付展示数据；缺少 SID、账号 ID、账号类型、收款码或接口返回错误时直接失败，不返回伪造成功结果。

运行态由 `RuntimePlugin` 契约和 `scripts/plugin-worker.php` 执行。清单必须明确声明 `heartbeat` 或 `cron` 能力，服务层才会调用对应方法。流水写入专用 `third_order` 表，并按插件、账号、第三方流水号去重；结算前再次校验收款账号、商户、金额和时间窗口。原 Go/Lua 私有正文仍只作为参考，不复制到 PHP 目录。

## PHP 服务器环境变量

```text
XARR_RUNTIME_DIR=/www/wwwroot/xarr-php-ys
XARR_PLUGIN_DIR=/www/wwwroot/xarr-php-ys/plugins
XARR_DB_HOST=127.0.0.1
XARR_DB_PORT=3306
XARR_DB_NAME=xarrpay
XARR_DB_USER=xarrpay
XARR_DB_PASSWORD=<只在服务器配置>
XARR_DB_CHARSET=utf8mb4
```

## 不允许放入本地源码的内容

- 真实数据库密码
- Redis 密码
- 商户密钥和支付渠道密钥
- 服务器运行日志
- `runtime/` 内容
- `plugins/pay/*.lua` 私有插件正文
- 生产数据库导出
