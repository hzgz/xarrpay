## 发现并修复的服务器条件

### Nginx 安装 API

原 Nginx 只对 `/install` 静态页放行，通用未安装拦截会把 `/api/install/*` 也跳回 `/install`，导致安装页面能打开但无法提交。

已在 HTTPS 的 `ys.973700.xyz` server 块增加独立 FastCGI 规则：

```nginx
location ^~ /api/install {
    include /www/server/nginx/conf/fastcgi_params;
    fastcgi_param SCRIPT_FILENAME /www/wwwroot/xarr-php-ys/public/router.php;
    fastcgi_param REQUEST_URI $request_uri;
    fastcgi_param XARR_DB_DSN sqlite:/www/wwwroot/xarr-php-ys/var/local.sqlite;
    fastcgi_pass unix:/tmp/php-cgi-xarr-ys.sock;
}
```

Nginx 已执行 `nginx -t` 并 reload，通过。

### PHP-FPM `putenv`

安装器需要写入 `.env` 并让当前请求读取配置；PHP 8.1 全局 `php.ini` 原先禁用了 `putenv`，真实安装时报：

```text
Call to undefined function XArrPay\Http\Controllers\putenv()
```

已备份：

```text
/www/backup/php81.ini.before-xarr-putenv-20260926210800
/www/backup/xarr-php-ys-fpm-before-putenv-20260926130400.conf
```

已从 `/www/server/php/81/etc/php.ini` 的 `disable_functions` 移除 `putenv`，其它禁用项保留；PHP-FPM 配置检查通过并重启成功。

当前远端检查：

```text
putenv=enabled
php-fpm-81=active
```
