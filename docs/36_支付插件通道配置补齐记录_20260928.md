## 2. 问题根因

插件清单已经统一使用支付方式值 `wxpay`，但本地运行数据库仍保留上一版测试数据：

```text
pay_type.wechat
pay_channel.demo-wechat
pay_account.wechat / demo-wechat
pay_codes.wechat / demo-wechat
```

`/api/pay/conf` 会要求支付通道的 `type` 与启用的 `pay_type.value` 严格相等。因此固定插件通道虽然已经写入 `pay_channel`，但因为数据库没有 `wxpay` 支付方式，被关联查询过滤，前台显示为空。

另外，`yun_wechat_yyb_xd/form.php` 复用了电脑管家表单后又重复追加 `flow_endpoint` 和 `flow_http_method`，导致应用宝配置项重复。
